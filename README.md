# ДЗ 3 — бюджеты в Ledger

В сервисе Ledger реализованы бюджеты по категориям. Если сумма расходов вместе с новой транзакцией превышает лимит, транзакция не сохраняется и возвращается ошибка.

## Бюджеты

Бюджет содержит категорию и лимит. Бюджеты хранятся в памяти, а функция `SetBudget` позволяет добавить или изменить лимит для категории.

Функция `LoadBudgets` загружает бюджеты из JSON. При запуске программа читает файл `budgets.json`:

```json
[
  {"category": "еда", "limit": 5000},
  {"category": "транспорт", "limit": 2000}
]
```

Если файл не удалось прочитать или JSON содержит ошибку, программа выводит сообщение об ошибке.

## Запуск

Нужен Go 1.22 или новее. Из корня проекта:

```sh
cd ledger
go run .
```

Запускать нужно из папки `ledger`, чтобы программа нашла `budgets.json`.

В примере расходы на еду достигают лимита 5000 рублей. Следующая покупка на 100 рублей отклоняется. В конце выводится список транзакций, в котором нет отклонённой покупки.

Бюджеты фиксированные, без разделения по месяцам. Данные хранятся в памяти и сбрасываются при перезапуске.

## Тесты

Из папки `ledger`:

```sh
go test ./...
```

Тесты проверяют добавление транзакций в пределах бюджета, отказ при превышении лимита, обновление бюджета, загрузку JSON и ошибки чтения.
