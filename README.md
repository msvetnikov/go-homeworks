# ДЗ 2 — Gateway и Ledger

В проекте два сервиса: `gateway` и `ledger`.

## Сервисы

Gateway запускает HTTP-сервер на порту 8080. На `GET /ping` отвечает `pong`.

Ledger хранит транзакции в памяти. У каждой есть ID, сумма, категория, описание и дата. В `main` добавляются три примера, затем выводится список. Транзакции с нулевой суммой не добавляются.

## Как запустить

Нужен Go 1.22 или новее.

В одном терминале из корня проекта:

```sh
cd gateway
go run .
```

Проверка в другом терминале:

```sh
curl -i http://localhost:8080/ping
```

В PowerShell используйте `curl.exe`. Ожидается `200 OK` и `pong`. Можно просто открыть адрес в браузере.

Для Ledger, из корня проекта:

```sh
cd ledger
go run .
```

В консоли появятся `Ledger service started` и три транзакции. После перезапуска данные сбрасываются.
